Document Structure & Metadata Tags

used in <head>

These tags live inside <head> and are not visually rendered — they provide metadata, load resources, and define document behaviour.

    details & summary (accordion)

    What is HTML?

    HTML stands for HyperText Markup Language. It is the standard language for creating web pages, describing their structure using a series of elements represented by tags.

    What is CSS?

    CSS (Cascading Style Sheets) controls the visual presentation of HTML elements — colours, fonts, layouts, animations, and responsive behaviour.

    What is JavaScript?

    JavaScript is a scripting language that adds interactivity and dynamic behaviour to web pages.

    Multi-Column

    Multi-column layout using column-count. Text flows naturally across columns just like a newspaper.

    You can also use column-width for responsive columns, column-rule for the divider line, and column-span: all to break across all columns.

    Add break-inside: avoid to prevent awkward breaks inside a specific element mid-column.

  from { opacity: 0; transform: translateY(20px); }
  to   { opacity: 1; transform: translateY(0); }

animation: fadeSlideIn .6s ease-out .2s 1 normal forwards;
/*         name   duration easing delay count direction fill-mode */
